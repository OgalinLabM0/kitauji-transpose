# 双语 EPUB：保留已有译文供对照

导入时自动识别以下格式。导入体检显示已有译文段数；在“翻译与阅读”点击“对比已有译文”查看。已有中文只供人阅读，不作为初译，也不发送给预读、术语、人物、翻译、审校或修复模型。

## 支持的排版

中日文逐段交替，可以中文在前，也可以日文在前；同一 XHTML 文件顺序一致。每对是同一父元素下相邻的两个 p 元素，日文用以下任一种方式明确标识：

- 段落自身带 `lang="ja"` 或 `xml:lang="ja"`，也支持 `ja-JP`。此时淡色可以来自外部 CSS，不要求行内样式。
- 日文段落带行内 `style="opacity:0.4;"`；中文不带此淡色标记。

中文在前：
```html
<p>雨还在下。</p>
<p lang="ja">雨がまだ降っていた。</p>
```

日文在前：
```html
<p style="opacity:0.4;">雨がまだ降っていた。</p>
<p>雨还在下。</p>
```

日文 ruby 注音和内联格式保留。不会仅因“没有假名”删除纯汉字或标点段落。元素之间可有空白或注释，但一对中间不能插入空 p、图片等元素。配对之外的图片、空行保留。语言标记冲突、配对不唯一或未配对正文会阻止导入，原文件不改动。

普通单语日文书全篇使用 lang="ja" 时，仍按单语书导入，不强行配对。

## 标题、附页与限制

已识别双语书中，未配对的附页内容仅原样保留，不发送给模型；其中自身明确标为日文的块仍进入待译正文。导入体检会提示附页数量，请检查是否有需要翻译却未标语言的正文。配对正文的未标语言标题保留用于显示和目录，不把中文标题交给模型；明确标为日文的标题仍可翻译。

不支持整章中日分开、左右表格、两种语言挤在同一个 p 中、同一文件混用两个排列方向。仅用外部 CSS/class 区分颜色但没有段落语言标记，也不在支持范围内；请先转换为上述结构。纯中文语言标记页仍可能因没有可配对日文而被拒绝，不保证识别任意双语 EPUB。

## 已有译文与导出

已有中文存入原书档案的独立只读记录，通过定位与日文对应，不成为待译段落、初译、最终稿或术语依据。只有专用阅读接口提取它；模型上下文不读取这些记录。

处理进度计算待译日文。导出时，配对位置的已有中文由软件译稿替换；未配对的展示标题、附页仍原样保留。生成的中文节点标为中文，不继承日文的淡色语言样式。原始 EPUB 快照保留，供定位与恢复。

旧版本若已把这本书作为混合原文导入，不会自动覆盖已有稿件。请先备份，再删除这一册并重导；无需清空整个书库。
